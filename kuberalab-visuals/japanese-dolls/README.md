# Japanese Doll Collection — Instagram & AI Motion Project

A complete content and production system for presenting a personal collection of Japanese dolls through Instagram Reels and short AI-generated motion films.

## Live page

https://kubera-lab.github.io/NikolaKubera/japanese-dolls/

## What this project contains

- a public portfolio page for the Japanese doll campaign;
- a strict seven-second Sora video prompt;
- formats for one doll, an imperial pair and a group display;
- rules that preserve faces, garments, accessories and character count;
- an Instagram caption structure with a clear follow call-to-action;
- a maximum of five internationally relevant hashtags;
- international audience targeting;
- verified-only rules for mentioning Japanese makers, studios and shops;
- links to the reusable prompt library.

## Core creative rule

The uploaded photo is used as the exact visual reference, but it must not appear as a separate frozen opening frame. The original doll or dolls begin moving immediately inside one continuous scene. No duplicate image, ghost copy, morphing or second version of the character is allowed.

## Instagram rules

- Write the main caption in natural English.
- Add tasteful Japanese symbols without visual clutter.
- Explain cultural meaning briefly and carefully.
- End with an invitation to follow and view the rest of the collection.
- Use no more than five relevant, high-reach hashtags.
- Do not add #KuberaLab unless explicitly requested.
- Mention makers, studios and dealers only after verification.
